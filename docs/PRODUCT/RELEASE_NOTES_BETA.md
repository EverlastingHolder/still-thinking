# Release notes beta

## Still Thinking 1.0 beta

Локальное iOS-приложение для фиксации незавершённых мыслей, отложенного возвращения и завершения цикла переосмысления.

## Что проверить

- Первый запуск и onboarding.
- Запись мысли и выбор времени возвращения.
- Получение возвращённой мысли на Today.
- Ответ, завершение или повторное отложение мысли.
- Archive, поиск и timeline.
- Settings: локальный privacy lock, настройки уведомлений, экспорт и удаление данных.

## Известные ограничения

- Данные хранятся только локально на устройстве.
- Синхронизации, аккаунтов и cloud backup нет.
- Экспорт создаёт JSON-файл с пользовательскими данными и должен передаваться только в доверенный канал.
- Текст мысли в уведомлениях отключён по умолчанию и включается только вручную.
- TestFlight upload требует distribution signing и доступ к App Store Connect.
